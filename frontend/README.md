# VoxGuard Frontend

**Date:** August 29, 2026

## Overview
A React + Vite application for detecting synthetic/AI-generated voices.

## Stack & Features Added Today
Built from scratch using **React, Vite, TypeScript,** and **Tailwind CSS v4**.

**Key UI Components:**
- **Audio Input:** Drag-and-drop file upload + live mic recording via `MediaRecorder` API.
- **Audio Preview:** Interactive waveforms powered by `wavesurfer.js`.
- **Analysis State:** Multi-step progress indicator.
- **Results Dashboard:** Color-coded verdict, confidence score, and metric breakdowns.
- **History:** Sidebar tracking recent scans in the current session.

## Quick Start
```bash
npm install
npm run dev
```
